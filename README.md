# ORB Visuals

Clean visual client for Fabric 1.21.11.

Style inspired by System — modern dark glass HUD, Dynamic Island watermark, compact Target HUD.  
No cheats.

## Controls
- **Right Shift** — open menu
- LMB on module — toggle
- Theme button in menu — switch Classic / New

## Features
- Target HUD (System style)
- Dynamic Island Watermark (FPS + logo + ms + time)
- Armor HUD, Inventory HUD, Keybinds, Notifications
- Waypoints, Coordinates
- Body Glow, Hand Glow, Trails, Star Glow
- Kill Effect, Custom Hand, Item Physics
- FullBright, Ambience

## Build
```bash
./gradlew build
```
JAR → `build/libs/`

Requires Java 21 + Fabric Loader + Fabric API.
